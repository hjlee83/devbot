# Task Contract Format

Each Task is a contract written before implementation.

Required sections:
- Goal
- Context
- In scope
- Out of scope
- Deliverables
- Functional requirements
- Quality gates
- Required test names
- Verification commands
- Git rules
- PR evidence requirements

Every quality checkpoint must identify at least one expected test name.
The implementing AI may add more tests but may not silently remove a required test.
